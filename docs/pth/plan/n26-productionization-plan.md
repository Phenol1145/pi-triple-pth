# N26 自主知识摄入生产化计划（草案）

> 日期：2026-08-24
> 前置：N29 最小可信摄入内环已 GO（`n29-minimal-intake-report.md` / `n29-minimal-intake-acceptance.json`）。
> 上游设计：`docs/pth/design/n26-autonomous-knowledge-intake-design.md`
> 状态：**计划草案**——外环设计尚未实施，本文先立生产化里程碑。

## 1. 目标

在 N29 内环基础上补外环：来源发现、自动扩源、多域广度、生产默认阈值与持续运营。

## 2. 工作项

### 2.1 来源发现外环

- 来源注册表 / 候选发现（种子来源 + 链接/索引发现）。
- 来源信任分级与人工准入边界。

### 2.2 自动扩源

- 多来源爬取调度、去重、变化检测。
- 与现有 intake outbox/stage handler 复用，不新建顶层模块。

### 2.3 多域广度

- 领域分类与知识广度目标；按域独立阈值与容量。
- 与 Role Catalog 的模块/Region 声明衔接。

### 2.4 生产默认阈值

- 将可行性/内环阈值升级为生产默认（并发、速率、超时、去重窗口、核验强度）。
- 全部可配置且默认 fail-closed。

### 2.5 持续运营

- 指标、告警、人工复核队列、来源健康度。
- 接 PTH Bench 受控测量与 sensor/controller 观测面。

## 3. 里程碑

| M | 内容 | 验收 |
|---|---|---|
| M1 | 来源发现外环 | 候选来源可发现、可准入 |
| M2 | 自动扩源 | 多来源调度/去重/变化检测绿 |
| M3 | 多域广度 | 按域阈值与容量生效 |
| M4 | 生产默认阈值 | 默认 fail-closed、可配置 |
| M5 | 持续运营 | 指标/告警/复核闭环 |

## 4. 未决问题

- 外环是否需要新表（来源注册表）还是复用 memory；
- 来源信任分级与人工准入的具体策略；
- 与 N28 Region 责任区的关系（official 知识进入 Region）。
